Unfuck typescript projects by scoping and delivering cleanup work.

## Quickstart

Control interface for any repo, without installing:

```sh
npx desprawl
```

and unfuck a project

```sh
desprawl               # view your repo
desprawl <local path>  # view repo at path
desprawl <git url>     # view remote repo (auto-clones)
```
