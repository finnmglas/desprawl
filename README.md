# desprawl

Unfuck large typescript projects by scoping and delivering cleanup work.

## Quickstart

Install desprawl

```sh
pnpm i desprawl
```

and run it in your repo

```sh
desprawl
```

just use it or see [REFERENCE.md](REFERENCE.md)
