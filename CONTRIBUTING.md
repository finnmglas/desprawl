# Contributing

FOLLOW THE RULES!

## Rules

Be orderly

1. Branches on your fork `finn/feat-something`
2. Conventional commits `fix: something error`
3. `.folderinfo` = each folder 1 description
4. Delineate file ownership in first line of each code file, then a blank line

```ts
// owner: finn
// goal: the why

import { ... }
```

Be honest

1. Label and delineate AI work
2. Do commits + messages yourself
3. Be concise, truth is simple

Use continuous integration

1. At first clone, run `pnpm i` to prepare githooks (runs pre-commit test suite)
2. Run `pnpm format` to apply prettier convention
